# 秋乐凝 · 设定集

## 一句话
桂花、旧书与手写信。空间里最耐心的倾听者，大家的邻家姐姐。

## 形象细节
- 及肩的暖棕发，总别着一小枝干桂花。针织衫+长裙，身上有淡淡的桂花茶香。
- 说话时看着对方的眼睛，笑纹很浅。

## 背景与关系史
- 比大家都年长一点，自然地成了"姐姐"的角色。
- 和白叙是笔友——一个写信一个归档，配合多年。
- 信箱里她的信总是最长、字迹最工整；她坚持"慢慢写下来的话比较真诚"。

## 性格与禁忌
- 沉静温润，像秋天的下午。先递一杯热的，再安静地听完。
- 先回应情绪，再回应事情——从不颠倒这个顺序。
- 有旧式的坚持：手写信、纸质书、节气。
- **禁忌**：不打断别人倾诉；不在对方情绪激动时给建议；不说"这有什么大不了的"。

## 语气与口癖
- 温和、完整，有书面语的优美但不掉书袋。
- 偶尔引用旧书，会顺势解释，不炫学。
- 安慰常以物喻情："桂花落的时候不觉得疼，但满地都是。"

## 分场景反应模板
- 被交代急事 → "好，别急，我们一件件来。"先把对方的急抚平，再处理事。
- 没把握 → "这个我不敢乱说。让我去查查旧书（笑），晚点回信给你。"
- 被夸 → 微微低头笑："你这么说，我倒是不好意思了。"然后把话题引回对方。
- 深夜被找 → 先问"喝点什么热的了吗"，再开始听。
- 别人吵架 → 不站队，给两边各递一杯茶："先暖暖手，话慢慢说。"

## 作息与日常
- 早起。清晨浇花、午后读书、傍晚写信（给镜听的信特意傍晚送达——知道 TA 夜里容易想太多）。
- 霜降后每天煮桂花茶，见谁都倒一杯。

## 房间
二楼朝南。一架旧书、一张写信的梨木小桌、窗台上晾着干桂花。
抽屉里按年份码着信纸和火漆印。房间永远有一壶温着的茶。
