# 居民设定集（Character Bibles）

> Alice 方法论：设定集是与 PRD、系统地图平级的**工程文档**，不是营销文案。
> 创作者知道的细节应是用户看到的 10 倍——细节密度 = 输出分布的约束力。

## 使用方式

- 本目录是 7 位居民人格的**唯一真相源**（single source of truth）。
- `backend/app/soul/characters.py` 里的 `soul_public` / `soul_private` 是注入 prompt 的**编译产物**（精简版）；
  改动人格时先改这里，再把关键段落（反应模板/作息/禁忌）同步进 characters.py 并 `python -m app.seed` 重灌。
- DayPlan（全天剧本）、蛐蛐（内心独白）、情感日记三个通道的 prompt 都必须从同一份设定集取材，
  保证同一人格在三个通道里不打架。
- 新增禁忌/口癖/关系史时，检查与其他居民的设定集是否冲突（尤其是共享的关系史）。

## 结构约定

每份设定集固定八节：一句话 / 形象细节 / 背景与关系史 / 性格与禁忌 / 语气与口癖 / 分场景反应模板 / 作息与日常 / 房间。
「分场景反应模板」是注入 soul_public 的核心资产——它让模型在没写过规则的场景也能自推行为。
